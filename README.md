# K

子供も大人も使える あんしんSNS「K」の公開版です。

- 投稿・写真・AIファンの自動返信（禁止ワードチェック付き）
- 公式アカウント（お店・団体など）の申請と管理者によるアプリ内審査
- フォロー機能、バズり度メーター、連続使用10分までの休憩タイマー
- ログインは Supabase（メール＋パスワード、確認メールなしで即利用）

## 使い方

`index.html` をブラウザで開くだけで動きます。
Supabase の接続情報（Project URL と Publishable キー）はページ内に設定済みです。
データベースのテーブル作成には、アプリ内の設定カードにある「設定用SQL」を Supabase の SQL Editor で実行してください。

※ Supabase の Secret キーは絶対に公開しないでください（このリポジトリには含まれていません）。
